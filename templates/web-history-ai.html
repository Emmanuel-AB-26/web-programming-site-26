History of the Web

A timeline of key events in the development of the World Wide Web.

  • Timeline
  • Key Technologies
  • References

1945

Vannevar Bush proposes the "Memex", a system in which information could be stored and connected through associative links.

1965

Ted Nelson developed the concept of documents being connected through links.

1980

At CERN, Tim Berners-Lee created "ENQUIRE", an information management system using linked information.

1989

The World Wide Web was proposed by Berners-Lee as a global hypertext system for sharing information among researchers at CERN.

1990

Berners-Lee developed the first web server, web browser/editor, HTML, HTTP, and URL system. The basic architecture of the Web was established.

1991

The Web was made publicly available beyond Berners-Lee's research circle.

1991

Other institutions began installing Web servers.

1993

CERN removed licensing barriers. This helped the Web spread rapidly and encouraged organizations worldwide to adopt it.

1993

Mosaic browser was released. Mosaic provided an accessible graphical interface and helped transform the Web from a research tool into a mass-market technology.

1994

W3C was founded by Tim Berners-Lee to coordinate Web standards.

1994

Netscape was founded, accelerating commercial Web browsing.

1995

JavaScript was introduced.

1995

Commercial web expanded rapidly through online shopping, search engines, and news sites.

1998

Google was founded.

Early 2000s

Web 2.0 appeared. The Web evolved from mostly static pages toward interactive services and user-generated content.

2004–2006

Social platforms such as Facebook and YouTube started to appear.

2007+

Smartphones made websites and Web applications accessible from mobile devices.

2010s

JavaScript, HTML5, CSS, APIs, and browser technologies allowed increasingly sophisticated applications to run directly in browsers, and websites increasingly adapted their interfaces to phones, tablets, and desktops.

2020s

The Web increasingly integrates cloud services, real-time applications, browser APIs, and AI-powered functionality.

Key Technologies

HTTP/HTTPS

The protocol used to request and transfer web pages and data between browsers and servers, with HTTPS adding encryption to secure that exchange.

HTML

The markup language used to structure the content of web pages, defining elements such as headings, paragraphs, links, and images.

URLs

Uniform Resource Locators identify the address of a specific resource on the Web, allowing browsers to locate and retrieve it.
