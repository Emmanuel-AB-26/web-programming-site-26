First Phase: 1945-1965

1945:Memex Appeared

Vannevar Bush proposes the “Memex”, a system in which information could be stored and connected through associative links.

1965:Ted Nelson Concept

Ted Nelson developed the concept of documents being connected through links.

Second Phase:1980-1989

1980:Berners-Lee created Enquire

At CERN, Tim Berners-Lee created “ENQUIRE”, an information management system using linked information.

1989:Berners-Lee proposes World Wide Web

The World Wide Web was proposed by Berners-Lee as a global hypertext system for sharing information among researchers at CERN.

Third Phase:1990-1998

1990:The basic architecture of the Web was established

Berners-Lee developed the first web server, web browser/editor, HTML, HTTP, and URL system.

1991:Web becomes publicly available

The Web was made publicly available beyond the Berner-Lee research circle.

Web Servers become more commonly available

Other institutions began installing Web servers.

1993:Mosaic browser was released and Cern removed licensing barriers

CERN removed licensing barriers. This helped the Web to spread rapidly and encouraged organizations worldwide to adopt it.

Mosaic browser was released. Mosaic provided an accessible graphical interface and helped transform the Web from a research tool into a mass-market technology.

1994:W3C and Netscape were founded

W3C was founded by Tim Berners-Lee to coordinate Web Standards.

Netscape was founded, and accelerated commercial Web browsing.

1995: Javascript was introduced and commercial web expanded

: Commercial web expanded rapidly through online shopping, search engines, news sites.

1998: Google was founded

Google appears as a search engine

Fourth Phase:2000-2010

Early 2000s: Web 2.0 appearance

The Web evolved from mostly static pages toward interactive services and user-generated content.

2004-2006: Social Platforms Appearance

Social platforms such as Facebook and YouTube started to appear.

Mobile devices are used for web browsing

Smartphones made websites and Web applications accessible from mobile devices.

Web technologies become more advanced

JavaScript, HTML5, CSS, APIs, and browser technologies allowed increasingly sophisticated applications to run directly in browsers and Websites increasingly adapted their interfaces to phones, tablets, and desktops.

Fifth Phase: 2010+

Latest technologies in Web

The Web increasingly integrates cloud services, real-time applications, browser APIs, and AI-powered functionality.
